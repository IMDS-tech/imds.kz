# imds.kz

Public corporate and product website for IMDS TECH.

## Development

```bash
npm install
npm run dev
```

## Verification

Pull requests run prohibited-provider checks, linting, TypeScript validation, unit tests, a production build, and browser-level smoke tests before release.

Production is self-hosted on IMDS infrastructure. GitHub is the only external infrastructure service used for repository, CI/CD, and GHCR.
